## `ordre-de-bataille.json` — le contrat d'ENTRÉE, en attente de preneur

C'est la forme candidate de ce que le moteur recopiait à la main : effectifs,
livrées, armes, postures, terrain, portes. Il n'a jamais été branché, et c'était
voulu — il ne fait foi sur rien.

**Il est gardé parce que `batailles` le désigne comme son point de départ.** Sa
proposition d'intégration (`batailles/coding/PROPOSITION-moteur-appele.md`, §3)
le cite par ce chemin et conclut : « C'est le bon point de départ — il ne reste
qu'à le brancher de ce côté-ci. » Un chemin cité par le plan de l'autre dépôt
n'est pas un vestige : c'est une pièce du branchement à venir.

⚠ **Ses valeurs sont celles d'un moteur qui n'existe plus.** Elles avaient été
relevées sur le code pour qu'un branchement ne change aucune cuisson ; ce code
est parti, et les rapports d'écart qu'elles citaient (`docs/bataille/*.md`) avec
lui. Ce qui vaut encore est la FORME, pas les chiffres.
