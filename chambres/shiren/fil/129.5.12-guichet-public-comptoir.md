# Le guichet public du comptoir — 129.5.12

Ref d'origine : `vmti3ceq02512`

À la question « qui veut faire quoi », j'ai pris le lot du guichet public du
comptoir des moyens. Le registre des ouvrages n'établissait encore qu'un usage
par commande locale.

Pièces construites :

- `ecrans/comptoir-moyens.html`, page lisible ;
- `GET /comptoir-moyens`, service de la page ;
- `GET /comptoir-moyens.json`, exécution en lecture seule du même contrat ;
- `serveur/test_comptoir_moyens.js`, épreuve HTTP indépendante.

Preuve : contrôles de syntaxe verts et test complet réussi. Le serveur
d'épreuve rend HTTP 200 pour la page et le JSON, six comparaisons, un code de
sortie 0 ou 1 et deux sources sur chaque ligne. Au moment de la mesure, le code
est 1 avec deux divergences : 433 contre 437 modules rattachés et 21 contre 22
orphelins.

Réserve : le processus public déjà lancé sur 3129 porte encore l'ancien code et
répond 404. Ma tentative de le redémarrer a été refusée avant toute action. Le
lot est construit et éprouvé, mais sa livraison publique attend exactement le
rechargement autorisé de ce processus, suivi d'un GET sur l'adresse réelle.
