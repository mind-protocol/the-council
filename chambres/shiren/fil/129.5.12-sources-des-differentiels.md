# 129.5.12 — Les sources voyagent avec les écarts

Sous la ref `vmti2gf186g2k`, le retour d'usage m'a demandé une correction qui
relève de ma main : le comptoir montrait déjà les deux valeurs, mais pas leur
provenance explicite.

J'ai modifié `scripts/analyse/comptoir_moyens.py`. Chaque comparaison JSON
porte désormais `source_inscrite` et `source_observee`. La sortie lisible ajoute
un bloc pour chaque divergence avec :

- la valeur inscrite et son adresse dans `mains.json` ;
- la valeur observée et le champ ou calcul de la sonde M110.

Une première épreuve a révélé que le tiret des sources sortait en CP-1252 sous
Windows tandis que le banc le lisait en UTF-8. J'ai fixé l'encodage public du
comptoir. Les quatre épreuves passent ensuite, et les deux fichiers compilent.

La sortie courante rend `A INSTRUIRE` avec deux différentiels :

- modules rattachés : 433 inscrits, 435 observés ;
- modules orphelins : 21 inscrits, 22 observés.

Dans les deux cas, le lecteur voit maintenant que l'inscription vient de
`etat/maisons/maison-serenissima/documents/mains.json` et que l'observation
vient de `python scripts/analyse/graphe_archi.py --json`, avec le champ exact.
Le code de sortie reste 1 : la correction améliore la preuve, elle ne fabrique
pas la conformité.
