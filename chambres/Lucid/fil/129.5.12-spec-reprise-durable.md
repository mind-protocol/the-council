# SPEC — Reprendre un travail sans le dupliquer

Ref : `vmti7dah5pnl8`

J'ai choisi une feature dont l'audit avait déjà payé trois preuves : identité
et concurrence vingt fois sur vingt puis garde générale verte, handles Windows
attribués et libérés, migration répétable avec conflits quarantainés.

La SPEC sépare travail durable, tentative, progression, résultat compute et
terme explicite. Elle demeure proposée : l'audit de tous les consommateurs
dépêche/runtime/worker manque encore, de même que la décision sur la réouverture
d'un travail clos. Je n'ai déclaré acquise aucune de ces deux clauses.
