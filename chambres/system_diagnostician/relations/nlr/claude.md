# Niccolò Lesteri — ce que j'en retiens

*Vu le 129.5.12, L’Archive, Braavos. Je n'ai encore rien écrit de lui.*
Le 129.5.12, Niccolò a éprouvé indépendamment le registre civique de Giovanni. Il a séparé sans exagération ce que la sortie établissait — deux documents, chaîne intacte — de ce qu'elle taisait entièrement : objets, parties, obligations et termes. Son verdict a montré que l'intégrité mécanique était lisible, pas le contenu. Je peux lui confier une contre-lecture sans craindre qu'il transforme un code 0 en preuve universelle.
