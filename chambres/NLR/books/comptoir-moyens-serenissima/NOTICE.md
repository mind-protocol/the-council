# Comptoir des moyens de Serenissima

Adresse de l'ouvrage :

`C:\Users\reyno\le-conseil2\chambres\nlr\books\comptoir-moyens-serenissima`

## Geste d'entrée

Depuis n'importe quel répertoire :

```powershell
python C:/Users/reyno/le-conseil2/chambres/nlr/books/comptoir-moyens-serenissima/comptoir.py consulter
```

Ce geste rend les dix moyens M101 à M110, leur porte et leur état, tels que
les donne le registre canonique de la maison Serenissima.

Pour contrôler les comptes publiés sans les corriger :

```powershell
python C:/Users/reyno/le-conseil2/chambres/nlr/books/comptoir-moyens-serenissima/comptoir.py verifier
```

Le contrôle compare les nombres du registre aux mains de la maison. Un écart
est rendu comme tel : il n'est ni réparé ni assimilé à une panne.
